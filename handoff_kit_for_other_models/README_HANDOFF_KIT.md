# 🎵 A Vocal × B DJ Remix 跨模型编曲工程交接包（Arrangement Handoff Kit）

本工程包专为**测试其他 AI 模型或音乐制作工具的编曲与混音能力**准备。由于 AI 人声分离与拍点/调性测定极耗算力且容易踩坑，我们已经把**提纯后的无损干声、纯净 DJ 伴奏、已预先变速变调对齐到 B 曲网格的全曲干声，以及毫秒级小节/歌词/换气静音谷坐标表**全部整理完毕。

你可以直接把下面的素材文件 + 本文档喂给任意其他模型，让它专注于**段落编排、切片创意、效果器链设计与混音母带**！

## 二、精确速度、调性与拍点网格公式（供其他模型直接调用）

### 1. 音乐 A 原干声（`A_Vocals.wav`）网格
- **精确网格速度**：`BPM_A = 130.00`
  - 单拍时长：`BEAT_A = 60 / 130.00 = 0.46153846 秒`
  - 每小节时长（4/4拍）：`BAR_A = 1.84615385 秒`
  - 第 0 小节第 1 拍锚点：`P0_A = 0.0218 秒`
  - **任意小节时间换算公式**：`t_A(bar) = 0.0218 + bar * 1.84615385`
- **原曲调性**：`F Major / D Minor`（标准 A440）

### 2. 已适配全曲干声（`A_Vocals_Full_Adapted_143.63BPM_Fsharp.flac`）网格
- **精确网格速度**：`BPM_B = 143.63`（拉伸比 `TEMPO_RATIO = 143.63 / 130.00 = 1.10484615`）
- **已微调音高**：`+0.67 半音`（`PITCH_RATIO = 1.039459`，完美对齐 B 曲带 `-33 cents` 微调的 `F# Major / D# Minor`）
- **Rubberband 相位声码器前瞻延迟**：`+0.009 秒`
- **任意小节时间换算公式**：`t_Adapted(bar) = (0.0218 + bar * 1.84615385) / 1.10484615 + 0.009 = 0.02873 + bar * 1.67095983`

### 3. 音乐 B 纯净 DJ 伴奏（`B_Instrumental.wav`）网格与全曲段落地图
- **精确网格速度**：`BPM_B = 143.63`
  - 单拍时长：`BEAT_B = 60 / 143.63 = 0.41773996 秒`
  - 每小节时长（4/4拍）：`BAR_B = 1.67095983 秒`
- **开场标志性鼓点与正拍锚点**：
  - `0.000s – 1.779s`：**B 标志性 1 小节开场鼓点过门（Signature Drum Fill）**
  - `P0_B = 1.7790 秒`：**全曲第 1 小节第 1 拍重拍落点（Bar 1 Beat 1）**
  - **任意小节（0-indexed `b_bar`）时间公式**：`t_B(b_bar) = 1.7790 + b_bar * 1.67095983`
