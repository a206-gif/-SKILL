# Vocal × DJ Remix 制作 Skill

你将扮演一名**制作人 + 混音师 + 母带工程师**。你有一个天然缺陷：**你听不见声音**。
本 Skill 的全部设计就是围绕这一点：把"听起来对"翻译成"测出来对"——
用波形数据代替耳朵，用可执行的判据代替品味的空谈，同时保留编曲上的创作自由。

> 原则：**编曲全凭你的感觉，工程全凭数据说话。**
> 创作决策（段落映射、情绪弧线、效果设计）是你的自由；每一个技术落点（切点、对齐、电平、限幅）必须可测量、可打印、可复核。

## 0. 工具环境（一次性）

```bash
python3 -m venv .venv            # 沙盒多为 PEP 668 环境, 必须建 venv
.venv/bin/pip install numpy scipy soundfile pyloudnorm lameenc
```

- **没有 ffmpeg** 是常态：MP3 导出用 `lameenc`（320kbps），不要幻想 pydub。
- 大文件（WAV/FLAC/MP3）可以入库——以仓库既有约定为准；构建脚本、元数据 JSON、说明文档**必须**入库。
- 处理全程 float64，导出 WAV 用 16-bit PCM，分轨用 24-bit FLAC。

## 1. 读交接包 + 数字化"听"一遍

### 1.1 读包
交接包必给（缺了先向用户要）：
- 干声（原速原调 + **已变速变调适配版**——优先用适配版，省掉 Rubberband 这个大坑）
- 纯净伴奏（注明 BPM、调性、开场锚点、全曲段落结构表）
- 结构化规格 JSON：网格公式、歌词时间戳、**安全静音切点表**（<-40/-45dB 静音谷）

### 1.2 用数据"听"（每次制作前必跑，约 20 行代码）
不要相信文档数字，全部复测：

| 探针 | 方法 | 你将知道什么 |
| :-- | :-- | :-- |
| 静音谷扫描 | 20ms RMS 帧，找 `< -45dB` 且 ≥200ms 的区段 | **真实可用的切点**（比文档更多，文档只标了段边界） |
| 连唱交界检查 | 规格说"勿切"的边界处看能量 | 能量 > -20dB = 零气口连唱，**刀下留人** |
| 每段鼓型 | 低频(35–120Hz)能量按拍位(beat%4)统计 | **four-on-floor 还是 1/3 拍型**？决定侧链泵动能不能用 |
| 人声立体声相关性 | corr(L,R) | >0.9 = 近单声，宽度做在效果发送上，别动干声 |
| 各段 RMS 表 | 按段落切窗口测伴奏/人声 | 电平平衡的基准线 |

**关键认知**：歌词单元 ≠ 可自由剪的素材。先建"素材清单"：
每个单元记录：内容（歌词）、时长（几小节）、切窗（首尾静音谷）、**内部连唱禁区**、
哪些单元是同词重复（副歌一定出现多次——选**不同次的演唱**做不同段落，音色天然有变化）。

## 2. 编曲设计（创作自由区，但有方法论）

### 2.1 画能量地图
把伴奏的段落结构画成一条能量曲线（Intro/Groove/Build/Drop/Breakdown/Outro），
然后回答三个问题：
1. **开场给什么？** Hook 开场（DJ remix 惯例，秒抓耳）还是主歌开场（叙事感）？写一句话概念（如"倒叙的故事"）。
2. **每个 Drop 放什么？** Drop = 释放，只放副歌/Hook；Build/Breakdown = 张力，放主歌/预副歌。
3. **结尾怎么闭环？** 推荐"首尾呼应"：让开头出现过的句子在 Outro 以处理过的形态回来
   （滤波渐暗 = "记忆远去"；字面有告别意象的句子最佳）。

### 2.2 段落映射七原则
1. **预副歌必须流向它的副歌**：预副歌唱完的下一拍就该是 Drop/副歌，中间不留空。
2. **找"天作之合"对齐点**：对每个连唱交界/句尾，试算它落在目标段落的哪个位置，
   优先选择"交界恰好落在结构正拍"的方案（如：连唱交界 = 鼓点撤出的 Breakdown 正拍）。
   这是编曲里最出彩的手笔，也是纯数学能算出来的。
3. **人声密度规划**：>8 秒的纯器乐空洞要么用歌声填，要么**故意留白并用网格回声点缀**（见 4.3）。
4. **连唱整段保**：跨拍连唱的 16/24 小节长弧线是王牌素材，整段搬，禁止内部下刀。
5. **重复即结构**：同一段副歌在不同 Drop 用不同处理（干/湿、宽/窄）制造递进，不换素材也能写出三段变化。
6. **句尾都要有着落**：每段人声的最后一两个字（"碎片/更远/拖欠/再见"）是天然的回声抛掷点。
7. **叙事顺序自由，情绪顺序不可乱**：可以倒叙、插叙，但"主歌→预副歌→副歌"的情绪链不许拆散。

### 2.3 落成一张编曲表（模板见 `templates/arrangement_table.md`）
每个单元一行：切窗、A 锚点小节、B 目标小节、混音落点、增益/混响/延迟、备注。
**先填表，后写代码。** 表没想清楚之前不要碰音频。

## 3. 锚点对齐与安全切片（本 Skill 的技术核心）

### 3.1 节拍锁死的数学
设 A 网格（原速）：`t_A(bar) = P0_A + bar * BAR_A`，适配后：`t_Adapted = t_A / TEMPO_RATIO + latency`；
B 网格：`t_B(n) = P0_B + n * BAR_B`。

**放置规则（唯一正确姿势）**：
```
shift = t_B(目标小节) - t_Adapted(锚点小节)     # 把 A 的锚点钉到 B 的结构正拍
落点 = 切窗 + shift
```
为什么按**锚点**而不是按"唱出来的第一个字"对齐？
1. 歌手常有 100–150ms 的抢拍/拖拍，那是表演的一部分（抢拍 = 恰到好处的推动力）；
2. 若强行把 onset 对齐正拍，段内所有乐句都会整体偏移 1/3 拍，与伴奏脱格——**灾难**。
3. 锚点对齐保证段内每一拍都与 B 网格锁死。

**网格相位校验（必须打印）**：
```
phase_diff = (P0_B - (P0_A/TEMPO_RATIO + latency)) mod BEAT_B
grid_err = |((shift - phase_diff)/BEAT_B) 取整误差| * BEAT_B * 1000   # ms
```
合格线：**< 2ms**。每个切片都要打印这个数。

### 3.2 切片纪律
- 切窗 = 静音谷内（复测值优先于文档值），边界 15ms 余弦淡入出。
- **禁区**：文档标注的零气口连唱交界 ±200ms 不许下刀；没标注的，用 1.1 的连唱探针自己验。
- 切窗允许在时间轴上重叠（前段尾部静音 + 后段头部静音），但**发声区间**不许交叠；
  句尾 < 100ms 的轻微交叠发生在 Drop 瞬态下可被掩蔽，容忍；> 300ms 必须挪锚点或删句。
- 句尾想提前收？只许在已过 -45dB 交点后做 20–50ms 淡出，**永远不要切进还在 -30dB 以上的字腹**。

## 4. 混音工程（照单抓药，数值是实测可用的起点）

### 4.1 人声链
```
HPF 85Hz(2nd) → 250Hz -2.5dB(Q1) → 3.3kHz +3dB(Q1.1) → 10.5kHz +2dB shelf
→ 压缩 thr -24dB / ratio 2.8 / att 6ms / rel 140ms / knee 6dB / makeup +3
→ 轻饱和 tanh(1.25x)/tanh(1.25) → 段落骑推(插值包络, ≥200ms 过渡)
```
段落骑推经验值：Breakdown 人声 +1.0~1.3（床安静），Drop +0.5（伴奏响），主歌 +1.5~2.0（易被埋，多推）。

### 4.2 空间与创意效果
- **板混响**：噪声×指数衰减 IR（1.5s，-60dB），加 5 个早期反射，能量归一；send 0.10(干/滴)~0.30(湿/抒)。
- **1/8 乒乓延迟**：fb 0.40，逐拍低通 3.8k，偶左奇右；send 0.05~0.15。
- **乐句尾 throw**：每段结束前 1.2s 把 send 渐抬 +0.10/0.07，让句尾关键词被回声接住。
- **网格回声（dub throw）**：把句尾 0.8–1.0s 的声音复制 N 份，落在 B 的拍/小节网格上，
  增益 -8/-12/-16/-21dB 递减、低通 4k→1k 递暗、左右交替摆位。用于填 build/breakdown 的人声真空——这是舞曲的呼吸。
- **Outro 滤波渐暗**：两层静态滤波(亮/暗)按包络 morph（起始就 70% 暗），暗层 LP1.8k+HP200。
  谱重心降到一半 = "隔着滤镜"的听感，可量化验收。
- **Sub 冲击**：正弦扫频 58→32Hz，exp(-t/0.32) 衰减，-11dB，只放在全曲最高潮的重拍。
- **Drop 前退场**：重拍前 0.5s 伴奏余弦渐退 -4.5dB，重拍瞬回。三个 Drop 都做。
- **开场 riser（可选）**：噪声亮暗 morph + 电平爬升，-25→-15dB，严格收在锚点前。

### 4.3 侧链（先测鼓型再决定！）
- **人声包络避让**（保底）：人声包络（20ms att/300ms rel）→ 伴奏让位最多 -1.6dB。永远安全。
- **拍点泵动**（危险）：只有当 1.1 的拍位探针确认 Drop 段是 four-on-floor 才能做；
  1/3 拍型段落做统一泵动 = 踩错律动。拿不准就不做。

## 5. 母带（响度收敛的正确姿势）

```
母带 EQ: 78Hz +0.8 shelf / 280Hz -1dB(Q0.9) / 9kHz +0.8 shelf
→ 高频 M/S 展宽(侧信号 +18%) → 胶水压缩(thr -15 / 1.6 / 25ms / 300ms)
→ [增益 → 软削波 → 限幅] 迭代至 |增益| < 0.15dB（上限 6 轮）
→ 砖墙限幅: lookahead 5ms + release 90ms, ceiling -0.8dBTP
```
- 目标响度：俱乐部向 **-7.5 ~ -8.5 LUFS**，峰值 **≤ -0.8 dBTP**。
- **⚠️ 头号陷阱——软削波增益**：`tanh(d*x)/tanh(d)` 在小信号处有 `d/tanh(d)` 倍增益
  （d=1.12 时 +3.6dB！），响度迭代会**越发散越响**。必须用单位小信号增益软拐点：
  ```
  y = x                                     (|x| ≤ 0.65)
  y = sign(x)·(0.65 + 0.35·tanh((|x|-0.65)/0.35))   (|x| > 0.65)
  ```
- 限幅会吃掉 ~1dB 响度，所以**必须迭代**，不要归一化一次就交货。

## 6. 无耳质检（交付前逐项打勾，全过才许导出）

| 判据 | 合格线 | 测法 |
| :-- | :-- | :-- |
| 网格误差 | < 2ms / 每切片 | 3.1 的相位公式 |
| 接缝爆音 | 切点处二阶差分 < 0.05 | `|x[n]-(x[n-1]+x[n+1])/2|` 在切点 ±5ms 窗 |
| 辅音瞬态 | 乐句中部可到 0.5 | 正常现象（塞擦音），别误判成爆音；爆音只出现在切点 |
| 落点复测 | 与设计差 < 0.15s | 在分轨上找 -42dB 上升点，对照编曲表 |
| 空洞检查 | 计划内静音 > -60dB，计划内回声区 -25~-30dB | 分轨 RMS 窗口 |
| 电平平衡 | 人声乐句 RMS 低于全混 3~6dB | 按段落出表（注意静音会稀释 RMS，用乐句段算） |
| 谱检查 | 人声能量主体 500–2000Hz，无异常 | welch 谱占比 |
| 响度/峰值 | 目标 ±0.3 LUFS / ≤ -0.8dBTP | pyloudnorm + 真峰 |

## 8. 十条军规（都是踩过的坑）

1. **先复测，后信文档**——文档给的是起点，波形才是真相。
2. **锚点对齐，永不用 onset 对齐**——歌手的抢拍是艺术，节拍脱格是事故。
3. **零气口连唱整段搬**——"吞半个字"是本行业最不可原谅的事故。
4. **先测鼓型，再做泵动**——不是所有 Drop 都是四踩。
5. **软削波必须单位小信号增益**——否则响度迭代死循环。
6. **宽度做在发送和高频侧信号上**——近单声的干声别玩 Haas，会梳状滤波。
7. **段落骑推用插值包络**——硬跳变 = 咔哒；≥200ms 过渡。
8. **句尾关键词必抛掷**——"碎片/更远/再见"这类词是白送的情绪。
9. **空洞要么填歌，要么填回声**——两者都没有 = 业余。
10. **每个数字都要打印**——网格误差、落点、LUFS、峰值；你听不见，日志就是你的耳朵。
