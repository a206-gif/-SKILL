# 网格数学与切片放置（Grid & Placement）

> SKILL.md 第 3 节的完整推导。这里的公式是通用的——把交接包的参数代进去即可。

## 1. 双曲网格定义

原速人声（A 曲）网格：
```
BEAT_A = 60 / BPM_A
BAR_A  = 4 * BEAT_A                      # 4/4 拍
t_A(a_bar) = P0_A + a_bar * BAR_A        # a_bar 允许 0.5 粒度（半小节锚点）
```
适配轨（变速变调后，与 B 同速同调）网格：
```
TEMPO_RATIO = BPM_B / BPM_A
t_Adapted(x) = t_A(x) / TEMPO_RATIO + LATENCY     # LATENCY = 相位声码器前瞻（如 Rubberband +0.009s）
BEAT_Adapted = BEAT_A / TEMPO_RATIO               # 精确等于 BEAT_B = 60/BPM_B
```
伴奏（B 曲）网格：
```
BEAT_B = 60 / BPM_B
BAR_B  = 4 * BEAT_B
t_B(n) = P0_B + n * BAR_B                # n = 距第 1 小节重拍的小节数（可为 0）
```

## 2. 锚点对齐定理

**任何切片的放置，只认锚点，不认 onset：**

```
shift = t_B(目标小节) - t_Adapted(锚点小节)
落点(t) = 切窗时刻 + shift
```

三个理由：
1. **表演微时序是素材的一部分。** 实测中「曾经是」的塞擦音 'z' 提前 140ms 越过 -45dB
   阈值——那是歌手在抢拍推动力。把 onset 硬怼到正拍，等于给整段表演加了 1/3 拍延迟。
2. **锚点对齐自动锁拍。** A 的每个拍点与 B 的每个拍点在适配后等距（同速），
   只要 shift 保持网格相位，段内所有乐句与 B 逐拍吻合。
3. **锚点即结构语义。** `a_bar = 8.0` 表示"这句从第 8 小节开始写"，把它钉到
   `B-bar 9` 的重拍 = 这句在新家也"从段落第一个小节开始"。

## 3. 网格相位校验

A、B 两曲的网格原点（P0_A、P0_B）是各自录音的任意相位，二者之差模一个拍长
就是**相位常数**：

```
phase_diff = (P0_B - (P0_A / TEMPO_RATIO + LATENCY)) mod BEAT_B
```

对任何"拍对拍"的放置，必须满足：
```
(shift - phase_diff) / BEAT_B ∈ ℤ
```
实测残差换算毫秒打印：`grid_err_ms = |frac| * BEAT_B * 1000`，合格 < 2ms。
（因为锚点和目标都取自各自的整拍/整小节网格，理论上自动成立；
 实测 0.001ms 级残差来自常数取舍——这就是合格线给 2ms 的原因。）

## 4. "天作之合"对齐点搜寻法

这是编曲里最出彩的一招，而且纯计算可得：

1. 列出人声所有**结构事件**：零气口连唱交界、长句句尾、半小节起唱的 Hook 头。
2. 列出 B 的所有**结构正拍**：段落切换点（Build→Drop、Groove→Breakdown……）。
3. 对每个候选放置（锚点→目标），算事件落点：
   ```
   事件落点 = 事件在适配轨的时刻 + shift
   ```
4. **评分**：事件落在结构正拍 ±0.2s 内 = 天作之合。优先采纳这些方案。
   - 例：连唱交界 = Breakdown 鼓点撤出的正拍 → 预副歌在无鼓氛围里推进（情绪核弹）
   - 例：零气口"再见→曾经是"交界 = Final Drop 重拍 → 副歌第一个重字砸在爆发点
   - 例：半小节起唱的 Hook 锚点钉到开场鼓点结束 → "鼓点一停立刻唱出"

## 5. 切窗纪律细则

### 5.1 静音谷是唯一合法刀口
- 自己复测 `< -45dB` ≥200ms 的区段（20ms 帧 RMS），**以复测为准**，文档值做交叉验证。
- 文档只标段边界；段内的乐句间空隙（0.3–0.9s 的换气谷）是免费的额外刀口，
  可以用来切半段、切单句——前提是该处两侧无连唱。

### 5.2 连唱探针
对文档标注"勿切"的边界（以及你怀疑的任何边界）：
```
边界 ±50ms 的帧能量 > -20dB → 零气口连唱，禁止切割
```
典型陷阱：「抱歉→奔跑」「再见→曾经是」，-13dB 直接连唱，切了必吞字。

### 5.3 发声区间重叠预算
切窗可以重叠（都是静音），发声区间尽量不重叠。预算表：
| 重叠量 | 处置 |
| :-- | :-- |
| < 100ms 且发生在 Drop 瞬态下 | 掩蔽效应覆盖，接受 |
| 100–300ms | 对旧句尾加 50–100ms 淡出后接受 |
| > 300ms | 挪锚点（换整小节目标）或放弃该方案 |

## 6. 落点微调（onset 只用于验收，不用于放置）

验收时在**成品分轨**上找 -42dB 上升点（30ms 窗 RMS），与设计预期对照：
- 塞擦音（z/c/s/ch）起音的字，实测 onset 比"感知起音"早 100–150ms；
- 浊音（b/d/g/元音）起音的字，实测 ≈ 感知起音。
对照表写清"期望区间"，落在 ±0.15s 内即合格。

## 7. 半小节锚点（x.5）说明

交接包若给出 `90.5` 这类半小节锚点，含义是"该乐句从第 90 小节第 3 拍起唱"
（半小节 = 2 拍）。把它钉到目标重拍，等于整句平移 2 拍的整数倍——**依然锁拍**。
实测案例：Hook「曾经是」半小节锚点 → 开场重拍，"曾经是"（抢拍）落在重拍前 0.14s，
"心心念念"落在下一个正拍上——起拍-落拍的呼吸感浑然天成。
